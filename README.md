# urbia · Workshops de tecnologías emergentes — Arquitectura Javeriana

Experiencia web inmersiva (React + Three.js + GSAP/Lenis) para presentar la propuesta académica de Ana Sofía Casas y Alejandra Gómez Gutiérrez.

- `npm run dev` — desarrollo
- `npm run build` — compila en `docs/` (GitHub Pages: rama main, carpeta /docs)
- Cronograma editable: `public/config/cronograma.json`
- Proyectos de las autoras: `src/data/autoras.ts`
- Textos: `src/data/contenido.ts`

Propuesta en discusión, no aprobada por la Facultad.
